## 조인·질의 규칙

- **법정동**(구서동) → 건물 테이블 `A4`. **행정동**(구서1동) → `BND_ADM_DONG_PG.ADM_NM` + `ST_Intersects`.
- 건물 ∩ 행정동 / 기초구역 / 산업단지 → 모두 `ST_Intersects(건물.geometry, 경계.geometry)`.
- D010 ↔ D198 속성 조인: `A1`(GIS건물통합식별번호) 또는 `A2`(PNU).
- 부산 산업단지: `AL_D060`의 `A4 LIKE '26%'` (전국 테이블).
- 경과년수·준공: `AL_D198.A34`(사용승인일자). D010 `A13`은 결측이 많아 쓰지 않음.
- D198은 **동래구·금정구만**. 그 외 구·시 전역 건물 건수는 D010.

### 장소·특수지 규칙

- 법정동(구서동, 온천동) → D010/D198 A4.
- 행정동(구서1동, 온천2동) → BND_ADM_DONG_PG ADM_NM + ST_Intersects.
- 구·군(금정구) → D010 A4 LIKE '%금정구%' 또는 D060 A4='26410' 또는 BAS SIG_KOR_NM='금정구'.
