# txt2sql 0.3.2 (2026-09-04)

제품 버전 **0.3.2**. Semantic Architecture v2 후속 작업(PlaceScope·Query Contract·plan repair·골드테스트1/2)을 `master`에 통합한다.

## 1. 요약

| 영역 | 내용 |
|------|------|
| PlaceScope | 행정동 BND, D010/D198 grain 정책 중앙화 |
| Query Contract | `verify_query_contract` — SQP·semantic_v2 공통 게이트 |
| Plan repair | Contract span 기반 deterministic repair (Q-ID 하드코딩 없음) |
| Fallback | `RANGE_BOUND`/`PREDICATE` soft-warning 후 실행, hard error만 fallback |
| 평가 | 골드테스트1(구질문)·골드테스트2(newset500) 분리 실행·비교 |
| 인코딩 | `run.py` UTF-8 `_safe_print` / `--log` |

## 2. 아키텍처

```text
질문 → extract_contract
     → (meta는 executable contract면 차단)
     → legacy route / semantic_v2 / SQP
     → validate → (repairable이면 plan_repair 1회)
     → compile_with_contract_gate
     → soft RANGE/PRED → execute | hard → fallback/clarify
```

핵심 모듈:

- `txt2sql/query_contract.py` — 통합 계약 검증, `contract_is_executable_query`
- `txt2sql/semantic_plan/plan_repair.py` — contract→filter/agg/group repair
- `txt2sql/dataset_grain.py` — D010 vs D198 grain
- `txt2sql/semantic_catalog/place_scope.py` — PlaceScope 바인딩

### 일반화 요지 (골드 ID 하드코딩 없음)

- **허가↔승인 시차**: `is_permit_approval_lag_question` / `assumptions_include_permit_lag`로 건축연령 라우트와 분리. D198 A33/A34 day-gap·비율·list ORDER.
- **구조 A11**: `exact_structure_label` / `structure_a11_predicate` — `…구조` equality, `일반목구조` 등 복합 수식은 ILIKE. 시 전체 exact count 허용. non_violation은 구조/용도 AND 유지.
- **컴파일·RAG 가드**: count+원컬럼 ORDER BY 제거, `ROUND(x,n)` → `ROUND((x)::numeric,n)`, 「N년 이내」를 공간 boundary로 오인하지 않음.
- **산업단지·BAS**: 단지별 건물 수/평균 연면적, 구·군별 단지 수, 높이 임계, 기초구역×행정동 HAVING.
